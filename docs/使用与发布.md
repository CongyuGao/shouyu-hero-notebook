# 守御手册：编辑、分享和公开发布

网站创作者：漫游的逗号。

## 现在在这台电脑上使用

- 普通查看：<http://localhost:3000/>
- 你自己的管理工作台：<http://localhost:3000/manage?page=workspace>
- 共同编辑者的密码入口：<http://localhost:3000/edit?page=workspace>

这些是本机预览地址；本地开发服务需要保持运行，不能把 localhost 发给别人当作公网地址。在别人的电脑上，localhost 指的是对方自己的电脑。

## 由你设置和更改编辑密码

1. 进入你自己的管理工作台，点“密码与分享设置”。
2. 在“编辑密码”中输入两次密码，点“保存编辑密码”，确认后保存。建议使用20位以上随机密码，不要使用QQ号、生日或重复字符。
3. 将“密码验证入口”复制给共同编辑的人，另行私发密码。他们不需要ChatGPT账号。
4. 你以后可在同一位置设新密码，无需找回旧密码。修改成功后，旧密码、已验证的旧编辑会话及以前的特殊编辑链接全部失效。
5. 其他人即使知道密码，也无法改密码、管理权限或生成特殊编辑链接。只有经站点所有者身份验证的你能做这些操作。

密码不是你的ChatGPT密码，请独立设置，不需要发到聊天或写进代码。共同编辑者持相同密码，无法据此区分具体编辑者。不要共用你的所有者账号。

本地预览使用开发用模拟身份，仅用于这台电脑；正式上线由Sites验证你的真实账号。不能直接把这个所有者身份机制搬到任意第三方主机，也不能把开发服务当公开服务器。

## 保存未完成的攻略

选英雄 → 编辑核心、小天赋、雕文、铭文和流派 → “保存草稿”。成功后窗口关闭，并返回工作台的“待完成攻略”。这里显示英雄、流派和保存时间，点“继续完成”可接着写。

普通玩家看不到草稿。已发布攻略再次保存草稿时，玩家仍看到此前的公开版本；只有你或其他获授权编辑者点“发布”后才更新公开内容。发布成功后该攻略移入“已发布攻略”。

## 分享只读与可编辑入口

- “只读链接”可以发QQ群：只显示已发布攻略。
- “密码验证入口”不包含密码，别人需输入密码才能编辑。
- 特殊编辑链接无需密码，但属于独立凭据，拿到或被转发的人都能编辑。可设1小时、1天、7天、30天，随时重置或作废。改密码也会作废这些旧链接。

只读预览只改变你当前的查看方式，不会自动收回别人的编辑权限。要收回权限，请更改/关闭密码，或作废对应特殊链接。

## 你自己公开发布的步骤

1. 用创建此站点的同一个ChatGPT账号及工作空间，在浏览器打开 <https://chatgpt.com/sites>。
2. 找到“守御手册”，打开已有站点，不要另建一个同名站点。
3. 打开“编辑”，在“描述网站修改”中提交下面这段请求。

   > 请使用守御手册所关联源代码仓库 main 分支的最新代码构建并公开部署现有站点。保留现有D1数据和所有者配置，不要部署早期旧版本。当前代码应包含页脚“网站创作者 · 漫游的逗号”、所有者独占修改密码、改密码使旧编辑权限失效，以及工作台“待完成攻略”。先保存新版本，再部署；只有部署成功后才给我HTTPS访问链接。如果发生错误，请告诉我具体失败阶段，不要把保存代码当作发布成功。

4. 如果要求确认访问范围，选择允许任何人查看并确认公开发布。
5. 等待明确的部署成功结果及HTTPS网站地址。仅看到源码已保存、GitHub已同步，或只有localhost地址，都不是公开发布成功。
6. 在公网网站进入 `/manage?page=workspace`，以你的所有者账号进入，重新设置编辑密码或生成特殊编辑链接。本地与线上数据库不同，本地测试密码/会话不会随代码上传。
7. 复制公网的普通查看链接发群，先用未登录窗口检查能否阅读。给编辑者的是公网密码入口或新生成的特殊编辑链接。

网站管理入口及“编辑”操作见 [官方Sites说明](https://learn.chatgpt.com/zh-Hans/docs/sites)。如果你看不到该站点或相应控件，先核对账号/工作空间，再提供画面；不要反复新建站点。网页版重试可能使用不同的上传路径，但不保证一定解决网络超时。

### 此前为什么没发出去

此前验证到的错误发生在上传部署包阶段：上传连接约60秒后超时，尚未得到公网部署地址。这个错误不是“等待审核”的提示；可能涉及连接、代理或上传服务，不能据此断言一定是你的网络。保存的早期版本不是最新网站，不应为了上线而退回它。

### GitHub与网站上线的区别

私有仓库 <https://github.com/CongyuGao/shouyu-hero-notebook> 保存源码、素材、迁移文件和已确认的初始公开资料。它不包含编辑密码、登录会话、本地数据库或私人草稿。

以后在网页里保存的内容进入网站数据库，不会自动提交到GitHub。本次同步代码也不是持续自动备份。数据库需另行导出/备份；攻略编辑器可导出攻略JSON。

当前项目有后端鉴权与D1持久化，不能只启用GitHub Pages就保留所有编辑功能。若改为其他托管方式，需另外适配数据库和可信所有者登录。不要把私有仓库改公开来尝试解决发布问题。
