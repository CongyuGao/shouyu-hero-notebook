# 守御手册

手机优先的无尽守御天赋与流派攻略平台。公开阅读，仅管理员指定的成员可编辑。

## 范围

- 首页只显示已经发布攻略的模式英雄，**不会把官网全英雄目录当成模式英雄池**。
- 每英雄默认6个核心、24个小天赋；天赋栏位可调整至1至36个，兼容18条资料。1至8个打法流派，各流派独立选择技能核心、雕文并评价天赋等级、理由与顺序。
- 支持模式专属雕文介绍（效果、适配与取舍）、逐流派勾选，以及雕文搭配说明、铭文、秘法和长篇实战说明。
- 草稿和公开版本分开保存，支持撤下、最近20次历史导出、JSON导入/导出。
- D1持久化、参数绑定、服务端权限、版本冲突保护；管理员按ChatGPT登录邮箱管理编辑成员。

## 数据边界

2026-09-06核验官网公开英雄目录（132条记录），这里只用于编辑选名称和头像。其记录数量不是无尽守御可用英雄数。

来源：https://pvp.qq.com/web201605/js/herolist.json

用户给出的 https://github.com/lengyibai/wzry 是常规王者资料项目，不包含可直接导入的完整无尽守御小天赋、模式雕文或核心流派数据。本项目没有复制该仓库代码，也不导入排位装备。

按用户要求先录入一位英雄：亚瑟“飞雷神连斩流”，来自 IMG_3111.PNG—IMG_3116.PNG。共6核心、24小天赋，保留原图勾选的3核心、6小天赋。`selected`仅代表截图已选，不代表强度推荐。版本日期尚未确认，标记待核验。腾讯文档的雕文尚未取得，不编造名称、效果或搭配。

`data/initial-guides.json`仅用于首次导入用户提供的资料；`lib/initial-guides.ts`用原子批处理 INSERT OR IGNORE 创建资料和历史，不覆盖现有编辑，也不会重新发布已撤下的攻略。数据库结构只由迁移创建，种子数据不进入迁移。

## 开发与部署

使用生成器指定版本，`pnpm install`、`pnpm dev`、`pnpm build`。数据库迁移由Drizzle生成并由Sites部署应用，不在请求中创建表。`db/schema.ts`为结构源。

本地 `.env` 的 ADMIN_EMAIL 使用Sites开发登录账号；生产 ADMIN_EMAIL 仅通过Sites管理。`.env` 不进入源代码或部署包。更改生产管理员需在Sites修改该值并发布，不可从公开界面修改。

`scripts/check-api.mjs`仅可对localhost运行，要求105英雄没有用户数据；创建带唯一TEST_ONLY前缀的临时数据并在finally清理。禁止用于正式站点。测试覆盖鉴权、来源校验、草稿隔离、发布、并发冲突、历史和成员授权。

WebMCP提供查询、打开、开始/填入编辑区和保存草稿，不允许绕过身份和版本检查；发布仍由界面明确操作。当前环境没有支持WebMCP的验证上下文，未声称完成浏览器WebMCP验证。未进行真实QQ/微信设备兼容性测试。
